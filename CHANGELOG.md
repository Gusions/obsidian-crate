# Changelog

## 0.4.0
- First public release.
- English and Italian interface, following the Obsidian language (or chosen in settings).
- Real covers without any account: public Apple search by artist and title, or Discogs with a release ID and token. Command "Fetch missing covers".
- Side panel is navigation and storage only; the collection view shows the active filters as chips (and its own tabs when the panel is hidden, e.g. on mobile).
- Theme-adaptive accent, grid and list layouts, facets (artist, genre, label, decade, location, tag), CSV import with column mapping.
